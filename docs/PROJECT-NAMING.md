# Project identity

- **Project and GitHub repository:** `CocAgent/OpenWorld`
- **Ecosystem:** OpenWorld
- **Execution and orchestration:** SuperKernel
- **Memory and learning:** HyperMemory
- **Mathematical models:** MathKernel
- **Simulation and social coordination:** World Runtime
- **Possible user-facing experience:** OpenWorld Companion

Official public language: **English**. Naming does not imply trademark exclusivity, AGI, consciousness or proved billion-agent scaling. OpenWorld remains entirely independent of AHappy.

## Historical naming proposals (not ratified)

The owner-provided discussions also used **AHappy World War**, **AHappy OpenWorld**, **OpenWorld: World Conflict**, **Open Civilization Protocol (OCP)** and **OpenWorld Protocol (OWP)**. These are earlier game concepts, branding options or proposed interfaces, **not** adopted replacement project names or public protocol standards. In particular, OCP may describe a future civilization/federation profile after W0 review; it is not the name of this repository. See [session synthesis](project/SESSION-SYNTHESIS-20261028.md).
